# ООО «СтройМатериалы» — База данных (Модуль 1)

## Структура проекта

```
stroy-db-module1/
├── database.sql           # DDL: создание таблиц, индексы
├── import_data.sql        # DML: импорт всех данных
├── er_diagram.pdf         # ER-диаграмма (PDF)
├── generate_er_diagram.py # скрипт генерации диаграммы
└── import/                # исходные файлы данных
    ├── Tovar.xlsx
    ├── user_import.xlsx
    ├── Zakaz_import.xlsx
    ├── Punkty_vydachi_import.xlsx
    └── *.jpg / *.png      # фотографии товаров
```

## Схема БД (3NF, PostgreSQL)

| Таблица          | Назначение                        |
|------------------|-----------------------------------|
| `roles`          | Роли пользователей                |
| `users`          | Учётные записи                    |
| `order_statuses` | Статусы заказов                   |
| `categories`     | Категории товаров                 |
| `suppliers`      | Поставщики                        |
| `manufacturers`  | Производители                     |
| `units`          | Единицы измерения                 |
| `pickup_points`  | Пункты выдачи (36 адресов)        |
| `products`       | Товары (30 позиций)               |
| `orders`         | Заказы (10 заказов)               |
| `order_items`    | Состав заказов (связующая)        |

## Развёртывание

```bash
# 1. Создать базу данных
createdb stroy_materials

# 2. Применить схему
psql stroy_materials -f database.sql

# 3. Импортировать данные
psql stroy_materials -f import_data.sql
```

## Роли пользователей

| Роль                  | Возможности |
|-----------------------|-------------|
| Гость                 | Просмотр товаров (без фильтрации) |
| Авторизованный клиент | Просмотр товаров (без фильтрации) |
| Менеджер              | Просмотр товаров (фильтрация/сортировка/поиск), просмотр заказов |
| Администратор         | Полный CRUD для товаров и заказов |
