# Строительные материалы — Модуль 1

Десктопное приложение на Java (Swing) для управления складом строительных материалов. Реализует ролевой доступ (администратор / менеджер), полное управление каталогом товаров с поиском, сортировкой, фильтрацией и поддержкой изображений.

## Сборка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/drugsdealer/stroy-db-module1.git
cd stroy-db-module1
```

### 2. Собрать JAR со всеми зависимостями

Maven Wrapper уже включён в проект — **устанавливать Maven отдельно не нужно**.

**Windows (PowerShell / cmd):**
```bat
.\mvnw.cmd clean package -q
```

**Linux / macOS:**
```bash
./mvnw clean package -q
```

> Если Maven всё же установлен глобально, можно использовать `mvn clean package -q`.

После сборки в каталоге `target/` появится файл `stroy-db-module1-1.0-SNAPSHOT-jar-with-dependencies.jar`.

### 3. Запустить приложение

**Windows:**
```bat
java -jar target\stroy-db-module1-1.0-SNAPSHOT-jar-with-dependencies.jar
```

**Linux / macOS:**
```bash
java -jar target/stroy-db-module1-1.0-SNAPSHOT-jar-with-dependencies.jar
```

> При первом запуске автоматически создаются:
> - `stroy.db` — база данных SQLite с тестовыми данными
> - `picture.png` — картинка-заглушка для товаров без изображения
> - `images/` — папка для хранения загруженных изображений

## Архитектура и описание модулей

### `Main.java`

Точка входа приложения. Выполняет инициализацию БД, создаёт `picture.png`-заглушку (300×200 px, серый фон с надписью «Нет изображения»), директорию `images/`, устанавливает системный Look & Feel и запускает `LoginForm`.

---

### `DatabaseManager.java`

Содержит всю логику работы с базой данных SQLite (файл `stroy.db`).

**Методы:**

| Метод | Описание |
|-------|----------|
| `initialize()` | Создаёт таблицы, вставляет тестовые данные при первом запуске |
| `authenticate(username, password)` | Авторизует пользователя, возвращает `User` или `null` |
| `getProducts(search, sortBy, ascending, manufacturerIdFilter)` | Возвращает список товаров с учётом поиска, сортировки и фильтра по производителю |
| `getCategories()` | Список всех категорий |
| `getManufacturers()` | Список всех производителей |
| `addProduct(product)` | Добавляет новый товар |
| `updateProduct(product)` | Обновляет существующий товар |
| `deleteProduct(productId)` | Удаляет товар; бросает исключение, если товар присутствует в заказах |
| `isProductInOrder(productId)` | Проверяет, есть ли товар в заказах |
| `getNextProductId()` | Возвращает `MAX(id) + 1` для отображения будущего ID |

### `LoginForm.java`

Окно авторизации (заголовок: **«Авторизация — Строительные материалы»**).

- Поля: логин и пароль
- Кнопка «Войти» / нажатие Enter
- При неверных данных — диалог ошибки
- При успехе — открывает `ProductListForm`, закрывает себя

---

### `ProductListForm.java`

Главное окно приложения (заголовок: **«Список товаров — [логин] ([роль])»**).

**Панель инструментов (сверху):**
- Кнопка «Выйти» (с подтверждением)
- Строка поиска — мгновенный поиск по всем текстовым полям
- Выпадающий список сортировки: «Количество ↑/↓», «Цена ↑/↓», «Скидка ↑/↓»
- Выпадающий список фильтра по производителю (первый пункт: «Все производители»)
- Кнопка «Добавить товар» (только для администратора)

**Таблица (по центру):**

| Колонка | Описание |
|---------|----------|
| ID | Уникальный идентификатор |
| Наименование | Название товара |
| Категория | Категория товара |
| Производитель | Производитель |
| Цена (руб.) | Стоимость, 2 знака после запятой |
| Кол-во | Количество на складе |
| Скидка (%) | Действующая скидка |
| Единица изм. | Единица измерения |

**Панель действий (снизу):**
- Строка статуса: «Показано: X из Y товаров»
- Кнопки «Редактировать» и «Удалить» (только для администратора)
- Двойной клик по строке открывает форму редактирования (только администратор)

**Особенности:**
- Поиск, сортировка и фильтрация применяются **в реальном времени** без кнопки «Найти»
- Фильтр по производителю и поиск работают **совместно**
- Настройки сортировки сохраняются при изменении поиска и фильтра
- Открыть более одного окна редактирования **невозможно**: повторный клик выводит предупреждение и переводит фокус на уже открытое окно
- После любой операции (добавление, изменение, удаление) таблица **обновляется автоматически**

---

### `ProductEditForm.java`

Форма добавления / редактирования товара.

**Заголовок:**
- Режим добавления: «Добавление товара»
- Режим редактирования: «Редактирование товара — [название]»

**Поля формы:**

| Поле | Примечание |
|------|-----------|
| ID | Только при редактировании, только для чтения |
| Изображение | Превью 300×200 px; при отсутствии — заглушка `picture.png` |
| Наименование | Обязательное |
| Категория | Выпадающий список, обязательное |
| Описание | Многострочное текстовое поле |
| Производитель | Выпадающий список, обязательное |
| Поставщик | Текстовое поле |
| Цена (руб.) | Число ≥ 0, допускаются сотые доли |
| Единица измерения | Текстовое поле |
| Количество на складе | Целое число ≥ 0 |
| Действующая скидка (%) | Число от 0 до 100 |

**Кнопки:** «Сохранить» и «Отмена»

**Логика изображений:**
- Кнопка «Выбрать изображение» открывает диалог выбора файла (jpg, jpeg, png, gif)
- Выбранное изображение масштабируется до 300×200 px и сохраняется в папку `images/`
- Имя файла: `<название>_<timestamp>.<ext>`
- При замене изображения старый файл **удаляется**
- В БД хранится относительный путь вида `images/filename.png`

**Валидация:** при нажатии «Сохранить» проверяются все поля; в случае ошибок выводится единый диалог со списком всех нарушений.

**Подтверждение закрытия:** при наличии несохранённых изменений запрашивается подтверждение перед закрытием.

## База данных

Файл: `stroy.db` (SQLite, создаётся в рабочей папке при первом запуске)

### Схема таблиц

```sql
CREATE TABLE categories (
    id   INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL
);

CREATE TABLE manufacturers (
    id   INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL
);

CREATE TABLE users (
    id       INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT NOT NULL UNIQUE,
    password TEXT NOT NULL,
    role     TEXT NOT NULL   -- 'admin' или 'manager'
);

CREATE TABLE products (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    name            TEXT NOT NULL,
    category_id     INTEGER REFERENCES categories(id),
    description     TEXT,
    manufacturer_id INTEGER REFERENCES manufacturers(id),
    supplier        TEXT,
    price           REAL NOT NULL DEFAULT 0,
    unit            TEXT,
    quantity        INTEGER NOT NULL DEFAULT 0,
    discount        REAL DEFAULT 0,
    image_path      TEXT
);

CREATE TABLE orders (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    created_at TEXT NOT NULL,
    user_id    INTEGER REFERENCES users(id)
);

CREATE TABLE order_items (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    order_id   INTEGER REFERENCES orders(id),
    product_id INTEGER REFERENCES products(id),
    quantity   INTEGER NOT NULL,
    price      REAL NOT NULL
);
```

### Тестовые данные (вставляются при первом запуске)

**Категории:** Цемент, Кирпич, Металлопрокат, Трубы, Утеплители, Краска, Инструменты, Плитка

**Производители:** ЛСР Групп, КНАУФ, Технониколь, Bosch, Rehau, Caparol, СтройМикс, ЦеSiт

**Товары (6 шт.):** Цемент М500, Кирпич рядовой М150, Шпаклёвка KNAUF, Перфоратор Bosch GBH 2-26, Минвата Технониколь ROCKLIGHT, Краска Caparol Amphibolin

## Управление изображениями

- Изображения хранятся в папке `images/` рядом с JAR-файлом
- В БД хранится относительный путь: `images/<имя_файла>.<ext>`
- При загрузке изображение масштабируется до **300×200 пикселей** (с сохранением пропорций, незаполненные области — серые)
- При замене изображения старый файл автоматически удаляется
- Если файл изображения не найден или не указан, отображается заглушка `picture.png`

## Обработка ошибок

Все исключительные ситуации сопровождаются диалоговыми окнами с соответствующими иконками:

| Тип | Заголовок | Иконка | Примеры |
|-----|-----------|--------|---------|
| Ошибка | «Ошибка» | ❌ `ERROR_MESSAGE` | Неверный логин/пароль, отрицательная цена, попытка удаления товара из заказа |
| Предупреждение | «Предупреждение» | ⚠️ `WARNING_MESSAGE` | Не выбран товар, уже открыто окно редактирования |
| Информация | «Информация» | ℹ️ `INFORMATION_MESSAGE` | Успешное удаление товара |
| Подтверждение | «Подтверждение» | ❓ `QUESTION_MESSAGE` | Выход из системы, удаление товара, закрытие формы с несохранёнными данными |

Текст сообщений информативен: при ошибке валидации формы выводится список **всех** найденных нарушений с рекомендациями по исправлению.
